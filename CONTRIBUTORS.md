# Contributors

Thank you to everyone who has contributed to making this project better!

## Core Team

This project was created and is maintained by the RTPDBE community.

## Contributors

We welcome contributions from everyone! See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.

### How to Get Added

Contributors are added to this list when their pull requests are merged. Your contributions will be recognized in:

- This CONTRIBUTORS.md file
- CHANGELOG.md (for specific contributions)
- Release notes
- Git commit history

## Types of Contributions

We value all types of contributions:

- 💻 **Code** - Bug fixes, features, refactoring
- 📖 **Documentation** - Improving docs, writing guides
- 🐛 **Bug Reports** - Identifying and reporting issues
- 💡 **Ideas** - Feature suggestions and enhancements
- 🧪 **Testing** - Manual testing and test case creation
- 🎨 **Design** - UI/UX improvements
- 🌍 **Translation** - Internationalization support
- 📢 **Promotion** - Spreading the word
- 💬 **Support** - Helping other users

## Recognition

Special thanks to:
