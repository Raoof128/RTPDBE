# Screenshots

This directory contains screenshots for the extension documentation.

## Required Screenshots

To complete the documentation, please add the following screenshots:

### 1. popup-dashboard.png

**What to capture:**
- Open the extension popup
- Show the main dashboard with statistics
- Include protection toggle and current site status
- Recommended size: 400px width

**How to capture:**
1. Install the extension
2. Click the extension icon
3. Take screenshot
4. Save as `popup-dashboard.png`

### 2. warning-page.png

**What to capture:**
- Navigate to a test suspicious URL (e.g., `http://192.168.1.1/paypal`)
- Warning page should display
- Show suspicion score and reasons
- Recommended size: 600px width

**How to capture:**
1. Visit a suspicious URL pattern
2. Extension should redirect to warning page
3. Take screenshot
4. Save as `warning-page.png`

### 3. warning-banner.png

**What to capture:**
- Create a test page with suspicious content (password field on HTTP)
- Load the page
- Warning banner should appear at top
- Recommended size: 600px width

**How to capture:**
1. Create test HTML page with password field on HTTP
2. Load in browser
3. Warning banner appears
4. Take screenshot
5. Save as `warning-banner.png`

## Screenshot Guidelines

- **Format:** PNG
- **Quality:** High resolution, clear and readable
- **Privacy:** Don't include personal information
- **Annotation:** Optional arrows or highlights for clarity
- **Consistency:** Use same browser theme for all screenshots
